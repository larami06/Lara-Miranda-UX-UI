<a name="english"></a>
## 🇬🇧 English

### Overview
This project is an interactive, single-file UX/UI portfolio designed and built for **Lara Miranda**. It showcases 5 selected case studies spanning mobile applications, B2B retail tools, social engagement web platforms, and personal finance apps. 

The portfolio features a fully custom, lightweight Single Page Application (SPA) architecture written in vanilla JavaScript, complete with client-side routing, responsive layouts, embedded interactive Figma prototypes, and an isometric exploded laptop vector graphic generated programmatically.

### Features
- **Single-File Architecture (`index.html`):** Fully self-contained web app with HTML, embedded CSS (incorporating CSS variables, responsive clamp functions, and modern design tokens), and vanilla JavaScript routing.
- **Isometric Exploded Laptop Graphic:** Custom SVG graphic visualizing inner layers (chassis, board, SoC, battery, keyboard, screen interface) to match the sketchbook aesthetic.
- **5 Featured Case Studies:**
  1. **Members Book** (Disruption) — Exclusive mobile networking app for leaders and entrepreneurs.
  2. **Boy iPhones** (Apple-specialized retail) — Mobile sales management system.
  3. **Projeto Fortificar** (FORTES) — Social engagement and funding platform.
  4. **Rotinik** (Habits & productivity) — Social network for daily routines and productivity tracking.
  5. **FinTrack** (Personal finance) — Simplified mobile personal finance application with mascot integration.
- **Interactive Figma Previews:** Embedded iframe previews directly from Figma prototypes, paired with external quick-launch buttons.
- **Dynamic Navigation & Routing:** Hash-based routing system with seamless transitions between the main index and individual case studies.

### Tech Stack
- **HTML5** & **CSS3** (Custom Properties, Flexbox, Grid, Media Queries)
- **Vanilla JavaScript** (ES6+ SPA Router, DOM Manipulation)
- **Google Fonts** (*Playfair Display*, *JetBrains Mono*, *Inter*)
- **Figma Prototypes** (Embedded Hi-Fi interactive flows)

<a name="português"></a>
## 🇧🇷 Português

### Visão Geral
Este projeto é um portfólio de UX/UI interativo em arquivo único (Single-Page) desenvolvido para **Lara Miranda**. Ele apresenta 5 estudos de caso selecionados que abrangem aplicativos móveis, ferramentas de varejo B2B, plataformas web de engajamento social e aplicativos de finanças pessoais.

O portfólio possui uma arquitetura SPA (Single Page Application) leve e totalmente personalizada em JavaScript puro, contando com roteamento client-side, layouts responsivos, protótipos interativos do Figma embutidos e uma ilustração vetorial isométrica em camadas (laptop "exploded view") gerada programaticamente.

### Funcionalidades
- **Arquitetura em Arquivo Único (`index.html`):** Aplicação web autossuficiente contendo HTML, CSS embutido (com variáveis CSS, funções `clamp` responsivas e tokens de design modernos) e roteamento em JavaScript puro.
- **Ilustração Isométrica em Camadas:** Gráfico SVG personalizado representando as camadas internas do hardware (chassi, placa, SoC, bateria, teclado e interface de tela) alinhado à estética do projeto.
- **5 Estudos de Caso em Destaque:**
  1. **Members Book** (Disruption) — Aplicativo de networking exclusivo para líderes e empreendedores.
  2. **Boy iPhones** (Varejo especializado Apple) — Sistema móvel de gestão de vendas.
  3. **Projeto Fortificar** (FORTES) — Plataforma web de engajamento e fomento social.
  4. **Rotinik** (Hábitos & produtividade) — Rede social para gestão de rotinas diárias e hábitos.
  5. **FinTrack** (Finanças pessoais) — Aplicativo mobile simplificado de finanças pessoais com integração de mascote.
- **Visualizações Interativas do Figma:** Pré-visualizações incorporadas via iframe diretamente dos protótipos do Figma, acompanhadas de botões de acesso rápido externo.
- **Navegação & Roteamento Dinâmico:** Sistema de rotas baseado em hash (`#`) com transições fluidas entre a página inicial e os estudos de caso individuais.

### Tecnologias Utilizadas
- **HTML5** e **CSS3** (Custom Properties, Flexbox, Grid, Media Queries)
- **JavaScript Puro** (Router SPA ES6+, Manipulação do DOM)
- **Google Fonts** (*Playfair Display*, *JetBrains Mono*, *Inter*)
- **Protótipos Figma** (Fluxos interativos Hi-Fi embutidos)
